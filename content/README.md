# Как поменять меню на сайте

Всё меню сайта лежит в одном файле: **`content/menu.json`**. Чтобы поменять цену, скрыть
блюдо или добавить новое, достаточно исправить этот файл. Программировать не нужно.

Сейчас в файле выдуманное меню демо-версии. Для сайта клиента его заменяют блюдами клиента
(см. `HANDOFF.md`).

## Как устроен файл

В файле два списка:

- `categories` — разделы меню (Салаты, Супы, Гриль…), в том порядке, в каком они идут на сайте;
- `items` — блюда.

Одно блюдо выглядит так:

```json
{
  "id": "plov",
  "category": "main",
  "name": { "ru": "Плов", "kk": "Палау", "en": "Plov" },
  "description": { "ru": "Рис, баранина, морковь, нут, чеснок", "kk": "…", "en": "…" },
  "price": 2700,
  "photo": null,
  "available": true,
  "status": "пример (демо)",
  "check": { … }
}
```

| Поле | Что это |
|---|---|
| `id` | Короткое имя блюда латиницей, без пробелов. У каждого блюда своё. Не менять у существующих. |
| `category` | В какой раздел меню попадает блюдо — `id` одного из разделов (`categories`). |
| `name` | Название на русском (`ru`), казахском (`kk`) и английском (`en`). |
| `description` | Описание. Можно оставить пустым: `""`. |
| `price` | Цена в тенге, **только цифры**, без пробелов и знака ₸: `1900`. Сайт сам покажет «1 900 ₸». |
| `photo` | Имя файла фото из папки `assets/photos/menu/` или `null`, если фото нет. |
| `available` | `true` — блюдо показывается на сайте, `false` — скрыто. |
| `status` | Пометка для себя: `"не подтверждено"`, `"подтверждено"` и т.п. На сайте не видна. |
| `check` | Служебные пометки: откуда взяты данные. На сайте не видны, можно не трогать. |

**Переводы.** Если в `kk` или `en` стоит `"[TODO: перевод]"` или пусто, сайт покажет русский
вариант. Сами пометки `[TODO]` посетитель не увидит.

**Разделы демо-меню** (`category`): `salads` — Салаты, `soups` — Супы, `main` — Горячие блюда,
`grill` — Гриль, `sides` — Гарниры и хлеб, `desserts` — Десерты. Для клиента разделы можно
переименовать, удалить или добавить свои в списке `categories`.

## Поменять цену

1. Найдите блюдо в `menu.json` (в браузере на GitHub: клавиши Ctrl+F, введите название).
2. Исправьте число после `"price":`, например `"price": 1900,` → `"price": 2100,`.

## Скрыть блюдо (временно нет в наличии)

Поменяйте `"available": true` на `"available": false`. Блюдо пропадёт с сайта, но останется
в файле — чтобы вернуть, поставьте обратно `true`. Если в разделе скрыты все блюда, раздел
тоже исчезнет с сайта.

## Добавить новое блюдо

1. Скопируйте любое блюдо целиком — от `{` до `},` включительно — и вставьте сразу после него.
2. Поменяйте `id` на новый, которого ещё нет в файле (латиницей, через дефис:
   `"plov-s-kuricey"`).
3. Заполните `category`, `name`, `description`, `price`, `available`.
4. Фото: положите файл в `assets/photos/menu/` и впишите его имя в `photo`
   (например `"plov-s-kuricey.jpg"`). Нет фото — пишите `null` (без кавычек).
   Фото лучше квадратное, от 800 px. Сайт сам сделает из него маленькие лёгкие копии.
   Фото только те, на которые у клиента есть права (его собственные).
5. Раздел `check` у нового блюда можно удалить.

## Обслуживание, %

Процент обслуживания задаётся не здесь, а в `src/config/site.ts` (строка `serviceFee`).
Если поставить `0`, строка про обслуживание пропадёт с сайта.

## Осторожно с запятыми и кавычками

`menu.json` — строгий формат. Частые ошибки:

- текст всегда в двойных кавычках `"…"`; кавычки внутри текста — «ёлочки»: `"Блюдо «Домашнее»"`;
- между блюдами нужна запятая `},`, а после **последнего** блюда в списке — нет;
- в цене только цифры: `1900`, не `"1 900 ₸"`.

Если блюдо не появилось на сайте — проверьте, что `available` равно `true` и `category` точно
совпадает с одним из разделов. Если вместо фото текстовая карточка — проверьте, что имя
файла в `photo` совпадает с файлом в `assets/photos/menu/` буква в букву.

Если ошибиться с запятыми или кавычками, сайт не соберётся. Тогда Cloudflare **оставит в интернете прежнюю рабочую
версию**, а на GitHub у коммита появится красный крестик ✗. Ничего не сломается для
посетителей — нужно просто найти и исправить ошибку.

## Как изменения попадают на сайт

**Через браузер (проще всего):**

1. Откройте репозиторий на GitHub → папка `content` → файл `menu.json`.
2. Нажмите карандаш ✏️ («Edit this file»).
3. Внесите изменения.
4. Нажмите **Commit changes…** → кратко опишите, что поменяли («Цена плова 2900») → **Commit changes**.
5. Через 1–2 минуты Cloudflare сам пересоберёт сайт. Обновите страницу меню.

Посмотреть, что сборка прошла: на GitHub рядом с коммитом появится зелёная галочка ✓
(или в Cloudflare → Workers & Pages → проект → Deployments).

**На компьютере (для разработчика):** исправить файл → `npm run build` (проверка, что всё
собирается) → `git commit` → `git push`.

# Популярные блюда на главной

Шесть карточек «Популярные блюда» на главной берутся из списка `featured` в начале
`content/menu.json`:

```json
"featured": ["plov", "lagman", "lamb-shashlik", "caesar", "manty", "cheesecake"],
```

Чтобы заменить блюдо, впишите вместо старого `id` новый (из списка `items`). На главной
показываются только блюда с `"available": true` и с фото не меньше 500 px. Если у блюда
нет фото или оно мельче, сайт его просто пропустит. В демо-версии вместо фото показывается
пунктирная рамка «Фото блюда».

# Как менять акции

Акции на главной («Акции и бизнес-ланч») лежат в файле **`content/promotions.json`**.
Одна акция выглядит так:

```json
{
  "id": "business-lunch",
  "available": true,
  "title": { "ru": "Бизнес-ланч", "kk": "…", "en": "Business lunch" },
  "description": { "ru": "Салат, суп, горячее блюдо и напиток. …", "kk": "…", "en": "…" },
  "price": 2990,
  "priceFrom": false,
  "schedule": { "ru": "Пн–Пт, 12:00–15:00", "kk": "…", "en": "Mon–Fri, 12:00–15:00" },
  "check": { … }
}
```

| Поле | Что это |
|---|---|
| `id` | Короткое имя латиницей, у каждой акции своё. |
| `available` | `true` — акция на сайте, `false` — скрыта (но остаётся в файле). |
| `title` | Название на ru / kk / en. |
| `description` | Описание: что входит, условия. |
| `price` | Цена в тенге, только цифры (`3990`). Нет цены — `null`, и строки с ценой не будет. |
| `priceFrom` | `true` — цена показывается как «от 3 990 ₸». |
| `schedule` | Когда действует: «Каждую среду», «12:00–16:00». Пусто (`""`) — строки не будет. |
| `check` | Пометки для себя (откуда данные, что уточнить). На сайте не видны. |

- **Отключить акцию:** `"available": true` → `"available": false`.
- **Поменять цену или время:** исправьте `price` или `schedule` (на всех трёх языках).
- **Добавить акцию:** скопируйте любую акцию целиком (от `{` до `},`), поменяйте `id`
  и тексты. Порядок акций на сайте — как в файле.
- Если перевода на kk или en нет (пусто), сайт покажет русский текст.
- Акции с алкоголем в подарке (вино и т.п.) — сначала проверить по закону о рекламе алкоголя.

Правила с запятыми и кавычками — те же, что для меню (см. выше). Изменения попадают на сайт
так же: правка на GitHub → Commit → через 1–2 минуты сайт обновится.

# Страница «О нас»

Все тексты страницы «О нас» лежат в **`content/about.json`**, у каждого текста три языка
(`ru`, `kk`, `en`). Если в `kk` или `en` пусто, сайт покажет русский вариант.

| Поле | Что это на странице |
|---|---|
| `title` | Заголовок «О нас» |
| `lead` | Короткая строка под заголовком («Добро пожаловать!») |
| `intro` | Вступительный абзац |
| `expectTitle`, `expect` | Блок «Что вас ждёт»: у каждого пункта `title` и `text`. `"link": "menu"` добавляет ссылку «Всё меню» |
| `photos` | Фото блюд: `file` — файл из `assets/photos/menu/`, `dish` — `id` блюда из `menu.json` (его название станет подписью). Фото меньше 500 px не показываются. Пустой список в демо-версии — три рамки «Фото зала / блюда / команды» |
| `findTitle` | Заголовок блока «Как нас найти» (адрес и часы берутся из `src/config/site.ts`) |
| `bookButton`, `instagramButton` | Подписи кнопок |

- **Поправить текст:** найдите нужное поле и измените текст в кавычках на нужном языке.
- **Убрать пункт из «Что вас ждёт»:** удалите его целиком (от `{` до `},`), следите за запятыми.
- **Добавить пункт:** скопируйте любой пункт и поменяйте `id`, `title`, `text`.
- Поля `check` — пометки для себя (откуда взят текст). На сайте не видны.

**Важно:** на сайте клиента — только то, что подтвердил клиент. Историю заведения, шефа,
награды и т.п. добавляйте только с его слов.

# Как поменять название, контакты и ссылки

Название заведения и все контакты — в одном файле **`src/config/site.ts`**. Поменяли там —
изменится везде (шапка, первый экран, подвал, блок адреса, нижняя панель на телефоне,
кнопки доставки, превью ссылок).

| Что | Строка в `site.ts` |
|---|---|
| Название (ru / kk / en) | `name` |
| Номер WhatsApp для брони и вопросов | `whatsapp` — только цифры, с кодом страны, без `+` |
| Телефон | `phone` |
| Адрес (ru / kk / en) | `address` и, для поисковиков, `addressParts` |
| Режим работы | `hours` (текст на трёх языках) и `openingHoursSchema` (`Mo-Su 10:00-23:00`) |
| Кухня (для поисковиков, на английском) | `cuisine` |
| Instagram, 2ГИС | `instagram`, `map2gis` |
| Обслуживание, % | `serviceFee` (`0` — строка не показывается) |
| Яндекс Еда, Wolt | `delivery.yandexEda`, `delivery.wolt` (пусто или `[TODO…]` — кнопка скрывается) |
| Адрес сайта | `url` — при переходе на свой домен (нужен для превью ссылок и для поисковиков) |
| WhatsApp разработчика | `developer.whatsapp` — куда ведёт кнопка «Хочу такой сайт» в демо-версии |

Слоган, подзаголовок и текст сообщения о брони — в `src/i18n/ui.ts` (ключи `tagline`,
`hero.eyebrow`, `hero.slogan`, `booking.greeting`, `meta.*`, `og.imageAlt`).

Переключатели «демо / концепт / официальный сайт», кнопка прокрутки и нижняя панель — в
**`src/config/status.ts`** (см. комментарии в файле и `HANDOFF.md`).
