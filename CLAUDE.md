# CLAUDE.md — правила проекта (шаблон сайта для кафе и ресторана)

Шаблон сайта-визитки для кафе и ресторанов. Сейчас — **демо-версия**: выдуманное заведение
«Ваш ресторан» с пометками «Здесь будет ваш…»; кнопка «Хочу такой сайт» ведёт в WhatsApp
владельца проекта. Владелец продаёт такие сайты заведениям.
Подробное описание — в [BRIEF.md](BRIEF.md), чек-лист демо и нового клиента — в [HANDOFF.md](HANDOFF.md).

Шаблон сделан из концепт-сайта ресторана DADIANI (ресторан отказался). Данные, логотип
и фото DADIANI на сайт не возвращать.

## Общение
- Владелец проекта — не разработчик. Объяснять простыми словами: что делаю и зачем.
- Отвечать на русском языке.
- Демо-данные (блюда, цены, акции, адрес «ул. Примерная») — выдуманные, это нормально,
  на сайте они помечены как пример.
- Для сайта реального клиента — не выдумывать факты (адрес, часы, телефоны, цены, состав
  блюд, история, фото, ссылки). Если данных нет — спросить; до получения помечать `[TODO]`
  (например, `[TODO: адрес]`).

## Стек
- Astro + Tailwind CSS. Статический сайт: без сервера, без базы данных.
- Меню — один файл `content/menu.json` (категории, блюда, описание, цена в ₸,
  переводы ru/kk/en).
- Хостинг: Cloudflare Pages. Код: GitHub (`origin`, ветка `main`).
- Не добавлять библиотеки, интеграции, сервисы и скрипты (аналитика, виджеты и т.п.)
  без согласования с владельцем.
- Шрифты: только бесплатные с открытой лицензией (Google Fonts, лицензия OFL). Файлы
  шрифтов храним в проекте (не подключаем с чужих серверов). Платные и шрифты
  с неясной лицензией не использовать.

## Название, контакты и ссылки — в одном месте
- Название заведения (ru/kk/en) и все контакты и ссылки (WhatsApp, телефон, адрес,
  Instagram, 2ГИС, Яндекс Еда, Wolt, адрес сайта) хранятся ТОЛЬКО в `src/config/site.ts`.
  В других файлах их не дублировать — везде брать из этого файла.
- В демо `site.whatsapp`, `site.phone` и `developer.whatsapp` — номер владельца проекта
  (+7 707 928 48 83). Для клиента `whatsapp`/`phone` меняются на номер клиента,
  `developer` остаётся.

## Демо-режим (`src/config/status.ts`)
- `DEMO = true` — полоса «Это пример сайта» с кнопкой «Хочу такой сайт», блок в подвале,
  пометки `DemoHint` («Здесь будет ваш…») на блоках, рамки `PhotoPlaceholder` вместо фото.
- Новый блок на сайте — добавить ему пометку `DemoHint` (тексты `demo.hint.*` в `ui.ts`).
- `IS_CONCEPT` — плашка «Концепт-версия» для черновика сайта конкретного заведения.
- Для сайта клиента: `DEMO = false`; после подтверждения клиентом — `IS_CONCEPT = false`
  и `NOINDEX = false` (см. HANDOFF.md).

## Сайт клиента и передача
- Сайт клиента делать в копии проекта, демо оставлять как есть.
- Не привязывать сайт клиента в коде к личным аккаунтам владельца проекта.
- Не класть в репозиторий пароли, ключи, токены и другие секреты.
- Фото — только те, на которые у клиента есть права. Фото из сторис и чужие/стоковые не ставить.
- Держать `HANDOFF.md` актуальным: при каждом изменении, которое касается демо или
  передачи, обновлять его.

## Функциональность
- Страницы: Главная, Меню, О нас.
- Языки: русский (основной, в корне `/`), казахский (`/kk/`), английский (`/en/`).
  Переключатель РУ / ҚАЗ / EN в шапке. Каждая страница существует на всех трёх языках.
- Тексты интерфейса — только в `src/i18n/ui.ts` (ru/kk/en), не вписывать их в страницы.
  Новая строка интерфейса добавляется сразу на трёх языках.
- Казахские и английские тексты (в том числе мои переводы) проверяет носитель языка.
- Страница = общий компонент в `src/components/pages/` + три коротких файла-маршрута
  в `src/pages/`, `src/pages/kk/`, `src/pages/en/`.
- Нет корзины и приёма заказов. Доставка — только кнопки-ссылки на Яндекс Еду и Wolt.
- WhatsApp — ссылка `wa.me` с заранее заполненным текстом (бронирование, вопросы).
- Блюда без фото получают аккуратную текстовую карточку (без пустой рамки под фото);
  в «Популярных блюдах» демо-версии — рамка «Фото блюда».
- `content/reference/` (скриншоты) — в `.gitignore`, в git не хранить.

## Порядок работы
- Сначала план, потом код. Перед крупной задачей показать план и дождаться согласия.
- Небольшие шаги: одна понятная задача за раз.
- После каждого рабочего шага — `git commit` с понятным сообщением.
- `git push` на GitHub — только по просьбе владельца.
- Перед завершением задачи проверить, что сайт собирается (`npm run build` без ошибок).

## Дизайн
- Mobile-first: сначала вёрстка под телефон, затем планшет и компьютер.
- Стиль тёплый и уютный. Схема: **светлая с винной шапкой**. Шапка и подвал — `bg-wine`
  (логотип должен быть светлым), основной фон — `cream`. Для клиента цвета можно
  подобрать под его логотип.
- Шрифты: заголовки — Raleway (`font-display`, тонкие, заглавные, с разрядкой), текст —
  Inter (`font-sans`). Оба содержат все казахские буквы и знак ₸. Файлы — `public/fonts/`,
  подключение — `src/styles/global.css`.
- Цвета — только из `@theme` в `src/styles/global.css`, не вписывать коды цветов в страницы.
  На светлом фоне для текста использовать тёмные оттенки (`pomegranate-dark`,
  `rose-ash-dark`, `leaf-dark`): исходные коралловый и серо-розовый на креме читаются плохо.
- Новые шрифты проверять на казахские буквы (ә ғ қ ң ө ұ ү һ і) и знак ₸.
- Аудитория — люди со средним достатком, любой национальности: просто, понятно,
  без пафоса; цены и кнопки связи хорошо заметны.

## Команды
- `npm install` — установить зависимости.
- `npm run dev` — сайт на компьютере с автообновлением (http://localhost:4321).
- `npm run build` — собрать сайт в папку `dist/`.
- `npm run preview` — посмотреть собранный сайт из `dist/`.
- `npx astro preview stop` — остановить сервер preview (остановка фоновой задачи
  его не всегда завершает).
- `node scripts/make-images.mjs` — пересоздать значки и превью ссылки после замены логотипа.

## Структура папок
- `src/pages/` (+ `kk/`, `en/`) — адреса страниц; содержимое — в `src/components/pages/`. 404: `404.astro` в каждом языке; `kk/404.html` и `en/404.html` раскладывает маленький шаг в `astro.config.mjs` (Cloudflare показывает ближайший 404.html).
- `src/pages/sitemap.xml.ts`, `src/pages/robots.txt.ts`, `src/lib/seo.ts` — для поисковиков, включаются флагом `SEO_ENABLED`.
- `src/layouts/BaseLayout.astro` — общий шаблон (head, полоса демо/концепта, шапка, подвал, запрет индексации).
- `src/components/` — шапка, подвал и другие части страниц.
- `src/components/DemoHint.astro` — пометка «Здесь будет ваш…»; `PhotoPlaceholder.astro` — рамка вместо фото (обе для демо).
- `src/i18n/ui.ts` — языки, адреса страниц, переводы интерфейса (включая тексты демо `demo.*`).
- `src/lib/menu.ts` — чтение `content/menu.json`, фото блюд, формат цены, запасной русский текст.
- `src/lib/promotions.ts` — чтение `content/promotions.json` (акции на главной).
- `src/components/home/` — блоки главной: первый экран, популярные блюда, акции, доставка, адрес.
- `src/components/MenuCard.astro` — карточка блюда (фото через `astro:assets`, WebP, ленивая загрузка).
- `src/config/status.ts` — демо-режим (`DEMO`), пометка «Концепт-версия», запрет индексации, кнопка прокрутки (`SCROLL_BUTTON`), нижняя панель на телефоне (`MOBILE_BAR`).
- `src/lib/links.ts` — ссылки доставки (только заполненные) для первого экрана, блока «Доставка», подвала и нижней панели.
- `content/README.md` — инструкция: как править меню, акции, «О нас», контакты.
- `scripts/make-images.mjs` — создаёт `public/og-image.png` (превью ссылки 1200×630) и значки сайта из логотипа.
- `src/config/site.ts` — название, все контакты и ссылки, WhatsApp разработчика.
- `src/styles/global.css` — шрифты, цвета, подключение Tailwind.
- `assets/logo/logo.svg` — логотип (в демо — заглушка «LOGO»).
- `assets/photos/menu/` — фотографии блюд (в демо пусто).
- `content/` — данные сайта (меню, акции, «О нас»).
