# CLAUDE.md — правила проекта DADIANI

Сайт-визитка ресторана грузинской кухни DADIANI (Шымкент, Казахстан).
Подробное описание проекта — в [BRIEF.md](BRIEF.md).

## Общение
- Владелец проекта — не разработчик. Объяснять простыми словами: что делаю и зачем.
- Отвечать на русском языке.
- Не выдумывать факты о ресторане (адрес, часы работы, телефоны, цены, состав блюд,
  история, фото, ссылки на агрегаторы). Если данных нет — спросить. До получения
  данных использовать явные заглушки вида `[TODO: адрес]`.

## Стек
- Astro + Tailwind CSS. Статический сайт: без сервера, без базы данных.
- Меню — один файл `content/menu.json` (категории, блюда, описание, вес, цена в ₸,
  переводы ru/kk).
- Хостинг: Cloudflare Pages. Код: GitHub (`origin`, ветка `main`).
- Не добавлять библиотеки, интеграции, сервисы и скрипты (аналитика, виджеты и т.п.)
  без согласования с владельцем.

## Функциональность
- Страницы: Главная, Меню, О нас.
- Языки: русский (основной, в корне `/`) и казахский (`/kk/`). Переключатель языка в шапке.
  Каждая страница существует на обоих языках.
- Нет корзины и приёма заказов. Доставка — только кнопки-ссылки на Яндекс.Еду и Wolt.
- WhatsApp — ссылка `wa.me` с заранее заполненным текстом (бронирование, вопросы).

## Порядок работы
- Сначала план, потом код. Перед крупной задачей показать план и дождаться согласия.
- Небольшие шаги: одна понятная задача за раз.
- После каждого рабочего шага — `git commit` с понятным сообщением.
- Перед завершением задачи проверить, что сайт собирается (`npm run build` без ошибок).

## Дизайн
- Mobile-first: сначала вёрстка под телефон, затем планшет и компьютер.
- Стиль тёплый и уютный. Цвета и шрифты — по логотипу из `assets/logo/`.
- Аудитория — люди со средним достатком, любой национальности: просто, понятно,
  без пафоса; цены и кнопки связи хорошо заметны.

## Структура папок
- `assets/logo/` — логотип.
- `assets/photos/` — фотографии блюд и интерьера.
- `content/` — данные сайта (меню, тексты).
