# CLAUDE.md — правила проекта DADIANI

Сайт-визитка ресторана грузинской кухни DADIANI (Шымкент, Казахстан).
Подробное описание проекта — в [BRIEF.md](BRIEF.md).

У ресторана уже есть веб-меню с корзиной: https://dadiani.dkgroup.kz/ (ведём не мы).
Наш сайт — дополнительная визитка: о ресторане, фото, акции, бронирование.
Заказы на нашем сайте не принимаем.

## Общение
- Владелец проекта — не разработчик. Объяснять простыми словами: что делаю и зачем.
- Отвечать на русском языке.
- Не выдумывать факты о ресторане (адрес, часы работы, телефоны, цены, состав блюд,
  история, фото, ссылки на агрегаторы). Если данных нет — спросить. До получения
  данных помечать их как `[TODO]` (например, `[TODO: адрес]`).

## Стек
- Astro + Tailwind CSS. Статический сайт: без сервера, без базы данных.
- Меню — один файл `content/menu.json` (категории, блюда, описание, вес, цена в ₸,
  переводы ru/kk/en). Файлы `content/*-draft.json` — черновики из чужих источников,
  на сайт напрямую не подключаются.
- Хостинг: Cloudflare Pages. Код: GitHub (`origin`, ветка `main`).
- Не добавлять библиотеки, интеграции, сервисы и скрипты (аналитика, виджеты и т.п.)
  без согласования с владельцем.
- Шрифты: только бесплатные с открытой лицензией (Google Fonts, лицензия OFL). Файлы
  шрифтов храним в проекте (не подключаем с чужих серверов). Платные и шрифты
  с неясной лицензией не использовать.

## Контакты и ссылки — в одном месте
- Все контакты и ссылки (номер WhatsApp, телефон, адрес, Instagram, ссылки на Яндекс.Еду
  и Wolt, адрес сайта) хранятся ТОЛЬКО в `src/config/site.ts`. В других файлах их
  не дублировать — везде брать из этого файла.
- Сейчас в `site.ts` тестовый номер WhatsApp владельца проекта; в конце его заменят
  на номер ресторана (пункт в HANDOFF.md).

## Передача проекта
- Проект будет передан другому владельцу. Не привязывать сайт в коде к личным
  аккаунтам текущего владельца.
- Не класть в репозиторий пароли, ключи, токены и другие секреты.
- Держать `HANDOFF.md` (чек-лист передачи) актуальным: при каждом изменении,
  которое касается передачи, обновлять его.

## Функциональность
- Страницы: Главная, Меню, О нас.
- Языки: русский (основной, в корне `/`), казахский (`/kk/`), английский (`/en/`).
  Переключатель РУ / ҚАЗ / EN в шапке. Каждая страница существует на всех трёх языках.
- Тексты интерфейса — только в `src/i18n/ui.ts` (ru/kk/en), не вписывать их в страницы.
  Новая строка интерфейса добавляется сразу на трёх языках.
- Названия блюд пока только на русском; для kk и en — `[TODO: перевод]`.
  Казахские и английские тексты (в том числе мои переводы) проверяет носитель языка.
- Страница = общий компонент в `src/components/pages/` + три коротких файла-маршрута
  в `src/pages/`, `src/pages/kk/`, `src/pages/en/`.
- Нет корзины и приёма заказов. Доставка — только кнопки-ссылки на Яндекс.Еду и Wolt.
- WhatsApp — ссылка `wa.me` с заранее заполненным текстом (бронирование, вопросы).

## Правила меню (этап 6)
Источники-черновики: `content/menu-draft.json` (kamiqr), `content/menu-instagram-draft.json`,
`content/menu-dkgroup-draft.json`; сравнение — `content/menu-differences.md`.
- **Цены** — из dkgroup (рабочий источник, не подтверждён рестораном).
  Внимание: в меню Instagram цены у многих блюд выше — см. `menu-differences.md`.
- **Описания** — приоритет у Instagram и kamiqr. Описание dkgroup — только если других нет,
  и с пометкой «не проверено».
- Расхождения с алкоголем (чакапули, блюда «в вине/в пиве») — в `menu-differences.md`, раздел 5.
- Блюда без фото получают аккуратную текстовую карточку (без пустой рамки под фото).
- Фото Coca-Cola, «Натахтари» и картофеля фри на сайт не ставим.
- Для первого демо — только кухня: без бара и без детского меню (бар добавим позже).
- Фото из сторис Instagram на сайт не идут.
- `content/reference/` (скриншоты) — в `.gitignore`, в git не хранить.

## Порядок работы
- Сначала план, потом код. Перед крупной задачей показать план и дождаться согласия.
- Небольшие шаги: одна понятная задача за раз.
- После каждого рабочего шага — `git commit` с понятным сообщением.
- `git push` на GitHub — только по просьбе владельца.
- Перед завершением задачи проверить, что сайт собирается (`npm run build` без ошибок).

## Дизайн
- Mobile-first: сначала вёрстка под телефон, затем планшет и компьютер.
- Стиль тёплый и уютный. Цвета и шрифты — по логотипу из `assets/logo/`.
- Утверждённая схема (этап 3): **светлая с винной шапкой**. Шапка и подвал — `bg-wine`
  (логотип рассчитан на тёмный фон, надпись в нём светлая), основной фон — `cream`.
- Шрифты (утверждены): заголовки — Raleway (`font-display`, тонкие, заглавные,
  с разрядкой, как надпись на логотипе), текст — Inter (`font-sans`). Оба содержат
  все казахские буквы и знак ₸. Файлы — `public/fonts/`, подключение — `src/styles/global.css`.
- Цвета — только из `@theme` в `src/styles/global.css`, не вписывать коды цветов в страницы.
  На светлом фоне для текста использовать тёмные оттенки (`pomegranate-dark`,
  `rose-ash-dark`, `leaf-dark`): исходные коралловый и серо-розовый на креме читаются плохо.
- Новые шрифты проверять на казахские буквы (ә ғ қ ң ө ұ ү һ і) и знак ₸.
- Аудитория — люди со средним достатком, любой национальности: просто, понятно,
  без пафоса; цены и кнопки связи хорошо заметны.

## Команды
- `npm install` — установить зависимости.
- `npm run dev` — сайт на компьютере с автообновлением (http://localhost:4321).
- `npm run build` — собрать сайт в папку `dist/`.
- `npm run preview` — посмотреть собранный сайт из `dist/`.
- `npx astro preview stop` — остановить сервер preview (остановка фоновой задачи
  его не всегда завершает).

## Структура папок
- `src/pages/` (+ `kk/`, `en/`) — адреса страниц; содержимое — в `src/components/pages/`.
- `src/layouts/BaseLayout.astro` — общий шаблон (head, шапка, подвал, запрет индексации).
- `src/components/` — шапка, подвал и другие части страниц.
- `src/i18n/ui.ts` — языки, адреса страниц, переводы интерфейса.
- `src/lib/menu.ts` — чтение `content/menu.json`, фото блюд, формат цены, запасной русский текст.
- `src/components/MenuCard.astro` — карточка блюда (фото через `astro:assets`, WebP, ленивая загрузка).
- `src/config/status.ts` — пометка «Концепт-версия» и запрет индексации.
- `content/README.md` — инструкция для владельца: как править меню.
- `src/config/site.ts` — все контакты и ссылки.
- `src/styles/global.css` — шрифты, цвета, подключение Tailwind.
- `assets/logo/` — логотип (`logo.svg` — оригинал, `logo-tight.svg` — то же без пустых полей).
- `assets/photos/` — фотографии блюд и интерьера.
- `content/` — данные сайта (меню, тексты).
